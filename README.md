# ORSi Spec — ORSi-01 review draft

**ORSi = OperatoR System and Intelligence.**  
**Mission:** For AI Development, Distribution & Sustainability.

This document set is the **ORSi-01 review draft**, not an adopted, certified or ratified specification. Integration into the specification repository does **not** itself constitute a stable release. Its current first-profile identity is **ORSi-01 — Device-Associated AI Service Entitlements**.

[Read ORSi-01](proposals/orsi/README.md) · [Proposed core](proposals/orsi/specification/2026-11-18-DRAFT.md) · [File-scoped licenses](LICENSING.md) · [Release process](proposals/orsi/governance/RELEASE-PROCESS.md)

ORSi-01 proposes a small, provider-neutral contract that identifies the entitlement issuer, service, enrolled device, access status, validity and applicable provider terms. Credits, talk time, actual inference, active-use hours and subscription periods remain separate. Service tariffs, optional unlimited covered-device workflows, recharge and cloud inference arrangements are **provider-defined**. The project does not mandate a billing network, hardware architecture, supplier commission or universal spending cap.

**Participation is open to inference/model providers, AI application developers and other voluntary adopters.** Telecom operators and flash-memory/USB manufacturers appear only as **illustrative business and technical references**. Neither sector owns or governs ORSi, holds special veto or royalty rights, or must participate. Detailed case studies and blog content remain outside this specification. This document is **not a formal release candidate (RC)**.

**Draft integration is not standards ratification.** Proposed requirements, written scenarios and this draft do not certify security, usage accounting, provider implementations or legal rights. A dated stable release, certification or public release announcement requires its own explicit review and decision. Trademark, contributor rights and release stewardship remain open.
