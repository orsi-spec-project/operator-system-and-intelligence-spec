# ORSi-01 — Decision summary for candidate review

**Preparation candidate — not an adopted standard.** This summary preserves the current owner-approved editorial direction; it is not evidence of independent consensus. The fuller historical decision log remains in the private preparation workstream.

| Area | Current decision |
| --- | --- |
| Project | **ORSi — OperatoR System and Intelligence**; first profile **ORSi-01** |
| Scope | Minimal **device-associated AI service entitlement** meanings, not a runtime, payment gateway or hardware implementation |
| Provider autonomy | Providers independently choose prices, credits, talk-time products, subscriptions, included workflows, validity and recharge |
| Unit independence | **No mandatory conversion** between credits, conversation duration, active-use hours, real inference consumption or outcome quality |
| Unlimited | **Optional** enrolled-device plan for clearly included routine repetitions within disclosed validity; not unlimited free inference |
| Postpaid controls | Optional customer hard caps, alerts-only or explicitly authorized uncapped use; provider may have lawful capacity or credit controls |
| Multiple providers | Independent entitlements and accounts on a compatible device; no global wallet, mandatory commission or cross-provider ledger debit |
| Reuse | Approved known tasks may run as reviewed routines; do not claim nonexistent fresh supplier inference |
| Device truth | OS USB identity isn't cryptographic authenticity; offline state freshness is a separate assurance |
| Business ecosystem | Open to inference/model providers and AI developers; telecom and flash-memory/USB are examples and optional participants, not owners or required partners. Detailed sector cases are separate |
| Sector neutrality — D-021 | No telecom or flash-memory industry governance, veto, exclusive rights, compulsory royalty or mandatory membership **by industry role**; actual IP/brand stewardship remains unresolved |
| Licensing | Apache-2.0 technical specification, CC BY 4.0 supporting docs, subject to final rights review |
| Publication | Authorized review-draft integration does not create an official release, certification or adopted standard. Stable publication needs its own separate decision |

**Still unresolved:** source contributor rights, international naming/trademark risk, release stewardship, hardware/offline security evidence and actual provider/customer review. See [deferred decisions](DEFERRED-DECISIONS.md).
