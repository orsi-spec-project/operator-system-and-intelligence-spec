# ORSi-01 — Device-Associated AI Service Entitlements

**Status: `2026-11-18-DRAFT` · REVIEW DRAFT ONLY · NOT A RATIFIED OR CERTIFIED STANDARD.**

The primary [proposed specification](specification/2026-11-18-DRAFT.md) defines common entitlement meanings for a provider-issued AI service associated with an enrolled device. The rules are provider-neutral and do not set commercial tariffs, infer device authenticity from USB serials, or mandate a model/runtime architecture.

**Open participation:** AI developers and inference/model providers may participate without joining a telecom organization or using a particular USB manufacturer's hardware. Telecom and flash-memory are references only, not governors of ORSi. **Do not promote draft text to conformance:** actual paid offerings need disclosed material terms, and any stable release requires a distinct approval.
